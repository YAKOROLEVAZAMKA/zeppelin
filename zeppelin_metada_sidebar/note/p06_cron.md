## Поставить на расписание

Пока всё запускается руками: параграфы 1 → 3 (DDL из параграфа 2 нужен только первый раз).

Когда убедитесь, что каталог собирается правильно:

1. Иконка часов в шапке ноута → выберите интервал, например каждые 2 часа: `0 0 */2 * * ?`
2. Включите **Auto-restart interpreter on cron execution** — иначе соединения
   к ClickHouse и Greengage протухнут между запусками.
3. Убедитесь, что параграф 2 (DDL) не мешает: он идемпотентный, повторный
   запуск безопасен, но можно просто отключить его через
   *Run all* → снять галочку у параграфа.

`zeppelin.notebook.cron.enable=true` и `cron.folders=/` у вас уже стоят,
дополнительно ничего включать не нужно.

## Права на ноут

Панель читает **файл каталога**, а не этот ноут, поэтому раздавать доступ
к ноуту всей команде не нужно. Достаточно, чтобы к нему имели доступ те,
кто правит описания.

## Проверить каталог руками

```sql
-- где лежит колонка account_id
SELECT db_key, schema_name, table_name, data_type
FROM catalog.v_search WHERE column_name = 'account_id';

-- когда собирали последний раз
SELECT collected_at, n_tables, n_columns FROM catalog.snapshot
ORDER BY collected_at DESC LIMIT 5;
```
