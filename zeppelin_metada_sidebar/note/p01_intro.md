# 00. Metastore — каталог DWH

Собирает схемы, таблицы и **колонки** из ClickHouse, Greengage и PostgreSQL,
складывает в `metastore-db` и отдаёт боковой панели в Zeppelin.

| Параграф | Что делает | Как часто запускать |
|---|---|---|
| 1. Конфигурация | подключения из `.env`, проверка связи | при каждом запуске ноута |
| 2. DDL | создаёт `catalog.*` в metastore-db | один раз |
| 3. `load_catalog_data()` | собирает метаданные и пишет каталог | по расписанию |
| 4. Описания | заполнить `desc_*` вручную | по мере надобности |

**Что где лежит в `metastore-db`:**

* `catalog.desc_schema` / `desc_table` / `desc_column` — описания, которые пишете вы.
  Коллектор их **не трогает**.
* `catalog.obj_table` / `obj_column` — сырьё из системных каталогов.
  Полностью перезаписывается каждый прогон.
* `catalog.snapshot` — собранный JSON целиком, последние 30 прогонов.
* `catalog.v_search` — плоский вид для поиска SQL-ом.

Панель читает не базу напрямую (браузер не умеет в протокол PostgreSQL),
а файл `metastore-catalog.json`, который этот ноут кладёт в общий volume.
Отдаёт файл nginx.
